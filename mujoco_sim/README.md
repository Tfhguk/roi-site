# 3D симуляция MuJoCo

Запуск из корня проекта: **`start-mujoco.cmd`**. Откроется существующий интерфейс симуляции в браузере по адресу `http://127.0.0.1:8766/truck.html?mujoco=1`. Кнопки, выбор полигона, техники, маршрута, параметры, телеметрия и экспорт используются те же, что в 2D. Изображение и движение рассчитывает настоящий MuJoCo на компьютере. GitHub Pages самостоятельно исполнять Python не может. При первом запуске создаётся отдельное Python-окружение и устанавливаются зависимости. Нужны Python 3.10+ и Node.js в PATH.

«Сброс» возвращает машину к началу выбранной траектории внутри полигона, обнуляет время, груз, рейсы и восстанавливает начальный заряд. Начальная позиция хранится в положении тела шасси, а координаты его скользящих суставов — как относительные смещения. Поэтому стандартный сброс MuJoCo тоже сохраняет машину внутри полигона. Ответы от старого расчёта после сброса не применяются к новому.

```powershell
.\start-mujoco.cmd
.\start-mujoco.cmd --port 8767
# Отдельное нативное окно и командный режим остаются доступны:
.lan-tls\mujoco-venv\Scripts\python.exe mujoco_sim\simulate.py --workspace "C:\путь\roi-workspace.json"
.lan-tls\mujoco-venv\Scripts\python.exe mujoco_sim\simulate.py --soc .24 --capacity .3 --speed 20
```

JSON скачивается кнопкой экспорта рабочего пространства на сайте. Выберите файл `roi-workspace.json`, содержащий границу, зоны, карту глубин и самосвал. Экспорт результатов `truck-test.json` имеет другой формат. Без файла запускается демонстрационный полигон. Данные на сайте не изменяются. Для нескольких самосвалов пока выбирается первый.

В браузере: перетаскивание мышью вращает сцену, колесо меняет масштаб. Кнопки «За самосвалом» и «Общий вид» переключают камеру. Пауза, остановка и сброс находятся в верхней панели. Для своих проектов войдите в аккаунт через локальную страницу входа: браузерное хранилище localhost отдельно от GitHub Pages. В нативном окне: **F** включает слежение, **пробел** — паузу, **R** — сброс; панели MuJoCo скрываются Tab / Shift+Tab. Голубая линия — активный рабочий путь, жёлтая — путь к зарядке. Красные блоки — препятствия; цвета пола показывают глубину. Цвета границ: голубая транспортная область, оранжевая добыча, сиреневый склад, зелёная зарядка.

Рабочий цикл бесконечный: добыча → погрузка 4 с → склад → разгрузка 4 с → добыча. При снижении заряда машина тормозит, строит новый путь от фактической позиции, подъезжает к станции, совмещается с ней и заряжается. После отключения с грузом едет на склад, без груза на добычу. Для путей используется тот же JavaScript-планировщик глубин, границ, арукомаркеров и корпуса станции, что на сайте. Текущие приоритеты планировщика: минимальный максимальный перепад, сумма перепадов, длина.

## Что моделируется

Это тестовый стенд, а не цифровой двойник изготовленного устройства. MuJoCo интегрирует динамику шасси от ограниченных сил и момента, контакты с красными препятствиями и корпусом станции, шарнир кузова и три приводные оси станции. Координаты машины после запуска не перезаписываются; контроллер следует пути по фактическому положению. Шасси ограничено плоскостью тремя суставами x/y/yaw; боковое сопротивление заменяет сложную физику гусениц. Колёса показывают вращение, но не являются моделью контакта гусениц с грунтом. Опрокидывание, подвеска и деформация грунта не моделируются.

Глубина пока в условных единицах: учитывается в маршрутах и цвете пола, но не преобразуется в вертикальные метры. Физическое основание плоское. Препятствия имеют тестовую высоту 160 мм. Кузов и груз изображены упрощённо: сыпучих частиц нет, масса шасси при погрузке не пересчитывается, груз влияет на расчёт управляющей силы. Рабочие зоны не имеют силовых стенок; соблюдение границ обеспечивает планировщик.

Все размеры техники условные. Скорость 0,09 м/с, колея 110 мм и станция 300×200 мм взяты из тестовой конфигурации сайта, а не из подтверждённого CAD. Перемещение контакта станции 160 мм, высота 80 мм. Электрическая модель — упрощённая батарея 1S, внутреннее сопротивление 0,12 Ом и заряд CC/CV до 90 %: расчёт в Python, не электрический решатель MuJoCo. Заряд разрешён только после совмещения и выдвижения механизма, при потере положения ток отключается. Контакт проверяется геометрически, усилие разъёма не моделируется. Параметры реального JGA25-370 и батареи ещё требуют идентификации.

## Проверка без окна

```powershell
.lan-tls\mujoco-venv\Scripts\python.exe mujoco_sim\test_simulation.py
.lan-tls\mujoco-venv\Scripts\python.exe mujoco_sim\simulate.py --headless --seconds 500 --output test-output\mujoco.json
.lan-tls\mujoco-venv\Scripts\python.exe mujoco_sim\simulate.py --headless --seconds 1 --screenshot test-output\mujoco.png
# При запущенном локальном интерфейсе:
node test_mujoco.cjs
```

`--seconds` ограничивает модельное время; без него работа в окне продолжается до закрытия. `--speed` ускоряет воспроизведение, сохраняя длительности в модельных секундах. `--soc` — начальный заряд от 0,1 до 0,95; `--capacity` — тестовая ёмкость от 0,1 до 5 А·ч. Результат JSON содержит историю состояний и явную отметку `synthetic`.

Python API и окно: [официальная документация MuJoCo](https://mujoco.readthedocs.io/en/stable/python.html).
