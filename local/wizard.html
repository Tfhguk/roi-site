CUBORG / ГАРАЖ

Подключение настоящих роботов

Локальный компьютер

Один мастер вместо шести ручных токенов. Работает только на этом компьютере, не отправляет секреты в GitHub.

1. Supabase → 2. Выбор техники → 3. Готовая прошивка → 4. Калибровка

1. Связать с существующим Supabase

Если уже настроил Supabase для сайта, адрес и публичный ключ могут заполниться сами. Пароль аккаунта нужен только для входа, он не сохраняется.

Найти: Supabase Dashboard → проект → Connect. Либо Project Settings → API Keys. Secret / service_role сюда не вставлять.

Не подключен
Войти кодом из письма вместо пароля

Для числового кода необходимо настроить email OTP в шаблоне писем Supabase. Если приходит только ссылка, используйте вход по паролю.

2. Выбрать технику

Роботы загружаются из твоего «Гаража». UUID техники и идентификатор полигона вставляются автоматически. Все локальные токены создаются сами.

Без Supabase: добавить робота вручную (только локальная работа)

Повторный запуск сохраняет уже созданные токены и параметры роботов. До калибровки математической модели движение заблокировано.

3. Скачать персональную прошивку ESP32

В ZIP будет готовый config.h с UUID, токеном робота и адресом локального сервера. Вручную переносить токен не придется.

Прошивку загружать через Arduino IDE. Если нужен токен для диагностики, нажми «Показать» и «Копировать» возле соответствующего робота.

4. Запуск и безопасность

После настройки закрой мастер и запусти START-ROBOTS-WINDOWS.cmd. Для работы камеры отредактируй измеренные координаты четырех опорных ArUco-маркеров в local/tracker-private.json.

Не включай движение до калибровки. Параметр model.calibrated изначально false. Физическая аварийная кнопка и ограждение полигона остаются обязательными.
