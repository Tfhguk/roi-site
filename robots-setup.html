2. Сохранить локальную конфигурацию

Токены генерируются в браузере на этом устройстве. Сайт не отправляет их в GitHub и не сохраняет в Supabase. Можно импортировать прежние файлы, чтобы не менять уже выданные токены и калибровку.

ZIP содержит секретные токены и refresh token Supabase. Храни его локально. Не загружай его в GitHub, не отправляй другим людям и не публикуй.

3. Персональная прошивка ESP32

Для каждого настроенного робота создаётся отдельный ZIP с config.h, UUID, токеном и исходниками прошивки. Wi-Fi пароль попадает только в скачиваемый ZIP.

IP нужно посмотреть на компьютере командой ipconfig → IPv4-адрес активного Wi-Fi адаптера. Не указывай 127.0.0.1: ESP32 не сможет обратиться к компьютеру по этому адресу.

Не прошивай робота, пока не настроены камера, ArUco-якоря, полигон и математическая модель. Движение по умолчанию заблокировано.

Сначала создай конфигурацию.

4. Установить на локальный компьютер

  1. Скачай ZIP конфигурации и распакуй его в папку проекта ROI.
  2. Помести robot-private.json и tracker-private.json в папку local (с заменой, если импортировал старые файлы).
  3. На Windows запусти START-ROBOTS-WINDOWS.cmd. Если в конфигурации указан cloud-блок, локальный сервер сам запустит Cloud Bridge.
  4. Открой локальный адрес компьютера, проверь подключение, затем прошивай ESP32 через Arduino IDE.

GitHub Pages — только интерфейс настройки и генератор файлов. Браузер не может сам записывать файлы в папку проекта, определять IP-адреса сетевых адаптеров или запускать Windows-команды.
