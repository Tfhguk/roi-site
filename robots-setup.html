2. Сохранить локальную конфигурацию

Токены генерируются в браузере на этом устройстве. Сайт не отправляет их в GitHub и не сохраняет в Supabase. Можно импортировать прежние файлы, чтобы не менять уже выданные токены и калибровку.

ZIP содержит секретные токены и refresh token Supabase. Храни его локально. Не загружай его в GitHub, не отправляй другим людям и не публикуй.

3. Персональная прошивка ESP32

Для каждого настроенного робота создаётся отдельный ZIP с config.h, UUID, токеном и исходниками прошивки. Wi-Fi пароль попадает только в скачиваемый ZIP.

IP нужно посмотреть на компьютере командой ipconfig → IPv4-адрес активного Wi-Fi адаптера. Не указывай 127.0.0.1: ESP32 не сможет обратиться к компьютеру по этому адресу.

Не прошивай робота, пока не настроены камера, ArUco-якоря, полигон и математическая модель. Движение по умолчанию заблокировано.

Сначала создай конфигурацию.

4. Программы для локального компьютера

Этот архив содержит Robot Server, Cloud Bridge и ArUco Tracker. Без этих программ компьютер не сможет передавать команды между Supabase и ESP32 и получать координаты роботов с камеры.

Без секретных токенов и паролей

Это отдельный архив. Его нужно распаковать в ту же папку, что и ZIP локальной конфигурации. Не заменяй им файлы robot-private.json и tracker-private.json.

5. Установить и запустить

  1. Создай одну папку на компьютере и распакуй в неё ZIP конфигурации и ZIP программ.
  2. Установи Node.js 20 или новее и Python 3.11 или новее. Ссылки и дальнейшие шаги есть в README-LOCAL-SOFTWARE.txt.
  3. Один раз запусти INSTALL-TRACKER-WINDOWS.cmd для установки библиотек камеры.
  4. После измерения четырёх неподвижных ArUco-якорей заполни их координаты в local/tracker-private.json.
  5. Запусти START-ROBOTS-WINDOWS.cmd — он запускает Robot Server и Cloud Bridge.
  6. Отдельно запусти START-TRACKER-WINDOWS.cmd — он запускает камеру и отслеживание роботов.
  7. Персональный ZIP прошивки каждого робота открой в Arduino IDE и загрузи в соответствующую ESP32.

GitHub Pages только формирует файлы. Запуск локальных программ выполняется на компьютере пользователя. До калибровки полигона и модели движение остаётся заблокированным.
