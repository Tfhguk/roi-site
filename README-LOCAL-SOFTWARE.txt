ROI — ПРОГРАММЫ ДЛЯ ЛОКАЛЬНОГО КОМПЬЮТЕРА

В этом архиве находится программная часть, которой не было в ZIP конфигурации
и персональной прошивке ESP32.

СОСТАВ
- robot-server.cjs — локальный сервер команд и телеметрии роботов.
- local/cloud-bridge.cjs — получает задания из Supabase и передаёт их Robot Server.
- local/aruco-tracker.py — получает изображение с камеры, определяет положение
  роботов по ArUco-маркерам и отправляет координаты локальному серверу.
- START-ROBOTS-WINDOWS.cmd — запускает Robot Server; Cloud Bridge запускается
  автоматически, если в robot-private.json есть блок cloud.
- INSTALL-TRACKER-WINDOWS.cmd — один раз создаёт Python-окружение и устанавливает
  библиотеки камеры.
- START-TRACKER-WINDOWS.cmd — запускает ArUco Tracker.

ПОДГОТОВКА
1. Создайте одну папку, например ROI-Robots.
2. Распакуйте в неё roi-robot-local-config.zip и этот архив. Если Windows спросит
   объединить папки local или заменить README, соглашайтесь. Не заменяйте вручную
   robot-private.json и tracker-private.json файлами-примерами из этого архива.
3. Для локального сервера установите Node.js версии 20 или новее:
   https://nodejs.org/
4. Для камеры установите Python 3.11 или новее:
   https://www.python.org/downloads/windows/
   При установке Python включите Add Python to PATH.
5. Дважды щёлкните INSTALL-TRACKER-WINDOWS.cmd. Это нужно сделать один раз.

ЗАПУСК
1. Подготовьте и откалибруйте arena.polygon и модель роботов в
   local/robot-private.json. Пока модель не откалибрована, движение заблокировано.
2. Измерьте координаты не менее четырёх неподвижных ArUco-якорей в метрах и
   внесите их в local/tracker-private.json → anchors. Проверьте camera и yaw_offset_deg.
   Без четырёх видимых якорей трекер не сможет вычислять координаты.
3. Запустите START-ROBOTS-WINDOWS.cmd и оставьте окно открытым.
   Он запускает Robot Server и, при наличии cloud-настроек, Cloud Bridge.
4. Запустите START-TRACKER-WINDOWS.cmd и оставьте окно открытым.
5. Прошейте ESP32 отдельным персональным ZIP для каждого робота.

ВАЖНО
- Все три окна/программы должны работать на компьютере, подключённом к той же
  локальной сети, что и ESP32.
- В персональном ZIP прошивки находятся Wi-Fi пароль и токен робота.
- В ZIP конфигурации находятся токены и refresh token Supabase.
- Не публикуйте эти архивы, JSON-файлы или config.h в GitHub и не отправляйте
  посторонним.
- Не запускайте движение, пока не проверены полигон, калибровка модели, камера,
  аварийная остановка и направление моторов. Используйте физическую кнопку
  аварийного отключения и ограждение полигона.
- Программная остановка не заменяет физическую аварийную кнопку.
