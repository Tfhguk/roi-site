СПИСОК ФАЙЛОВ ДЛЯ ПУБЛИКАЦИИ НА GITHUB

Теперь .lan-tls/update-github.cjs не содержит отдельный вручную поддерживаемый список файлов.
Он читает массив путей из github-files.json в корне проекта.

КАК ДОБАВИТЬ НОВЫЙ ФАЙЛ В ПУБЛИКАЦИЮ
1. Создайте или измените файл в проекте.
2. Откройте github-files.json в корне проекта.
3. Добавьте относительный путь к файлу отдельной строкой в JSON-массив.
   Пример: "local/new-module.cjs"
4. Сохраните файл. Проверьте JSON запятую между элементами.
5. Запустите обычную публикацию через check-github.cjs.

ВАЖНО
- Пути указываются относительно корня проекта, без начального /.
- В список нельзя добавлять .lan-tls, node_modules, dist, .env,
  личные конфигурации, приватные ключи и файлы с секретами.
- Примеры конфигураций с суффиксом .example.json можно публиковать,
  если в них нет реальных паролей и токенов.
- update-github.cjs остаётся локальным инструментом публикации в .lan-tls;
  сам он и данные авторизации GitHub не отправляются в репозиторий.
